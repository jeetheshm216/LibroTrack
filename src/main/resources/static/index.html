API & System Information

Architecture, database connectivity, and Postman API reference

Backend Architecture
Framework: Spring Boot 4.1.1
Runtime: Java 17 (JDK-17)
ORM / Persistence: Spring Data JPA / Hibernate
Base URL: http://localhost:8080
Backend Status: Connected
Database Configuration
RDBMS Engine: MySQL Server 8.0
Database Name: librotrack
Host / Port: localhost:3306
Tables: books, students, issue_records
DDL Mode: update
Business Rules Enforcement
Availability Check: Service layer: copies > 0
Loan Duration: 14 Days (Auto-calculated)
Fine Calculation: ₹5 per day overdue
Transaction Safety: @Transactional atomic rollbacks
Duplicate Return: Strictly prevented
